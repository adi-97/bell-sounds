# Bell Sounds

A single-page web app that rings temple bells. You can tap, swipe or shake your phone, or press a button. All sounds are generated in the browser with the Web Audio API, so there are no audio files.

## Bells
Pooja Bell · Temple Bell 1 · Temple Bell 2

## Ways to ring
- **Ring once**: tap the bell or press **Ring once**
- **Ring continuously**: open settings (⚙️) and set it to On. Press **Stop ringing** on the main screen to stop.
- **Swipe**: drag back and forth across the bell. It rings each time you change direction, and faster swipes ring louder.
- **Shake**: open settings (⚙️) and set "Shake to ring" to On (on iPhone, allow motion access when asked)
- **Settings** (⚙️ top right): choose the bell, continuous ringing, volume, echo, continuous speed, shake on/off and shake sensitivity
- **Keyboard**: Space rings once, C turns continuous ringing on or off, 1–3 picks a bell
